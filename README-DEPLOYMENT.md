# Vercel Deployment

This package is configured for direct Next.js deployment on Vercel.

- Framework: Next.js
- Install: `npm install --include=dev --no-audit --no-fund`
- Build: `npm run build`
- Output: `.next`
- Node: 22.x
- No pnpm/Corepack dependency

Set the variables listed in `.env.example` in Vercel Project Settings.
